# Season Maker
A simple java program to create folders for your seasons in an easy way

# IMPORTANT!!
You **MUST** have Java 8 or above installed to run the program, otherwise it will not work...

## How do I use it?
1. Choose a folder where to create folders
2. Select the spin in how many seasons you want to have (Choose "Include season 0" if you wanna add a season 0 of your show)
3. Once ready push "Make!" button and voila!
